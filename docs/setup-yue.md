## 1. 系統簡介

**帙雲** 係一個基於 Google Apps Script 嘅課業管理系統，自動化以下流程：

- 收集學生上傳至共用 Google Drive 資料夾嘅課業檔案。
- 將檔案按班別、科目自動分類至對應子資料夾。
- 將老師批改後嘅檔案自動發還至各學生專屬資料夾。
- 自動將學生資料夾共用並記錄連結。
- 在控制面板顯示課業繳交狀況（已繳交 / 遲交 / 未繳交）。

整個系統完全運行於**學校 Google 帳號**之內，無需外部伺服器或第三方服務。

---

## 2. 安裝前準備

| 項目 | 要求 |
|------|------|
| Google 帳號 | 學校 Google 帳號（例如：`teacher@ccckyc.edu.hk`） |
| Google Drive API | 需在 Apps Script 專案中啟用進階 Drive 服務（Drive API v3） |
| 瀏覽器 | 任何現代瀏覽器（建議使用 Chrome） |
| 學生電郵格式 | `{學號}@ccckyc.edu.hk`（例如：`s12345@ccckyc.edu.hk`） |

> **注意：** 如學校使用不同電郵域名，請在部署前修改 `code.gs` 中的 `ccckyc.edu.hk` 字串。

## 4. 步驟二：一鍵安裝系統

1. 打開剛剛建立副本嘅試算表。
2. 點擊最上方選單嘅 **「☁️ 帙雲系統」 → 「🚀 一鍵初始化系統」**。

### 首次執行授權（Google 安全提示）

由於呢個係內部開發嘅程式，Google 首次執行時會顯示授權視窗：

| 提示畫面 | 操作 |
|---------|------|
| 「Google 未驗證這個應用程式」警告 | 點擊左下角**「進階」** |
| 「前往『未命名專案』（不安全）」連結 | 點擊該連結 |
| 權限清單 | 點擊**「允許」** |

3. 授權完成後，請**再次**點擊 **「☁️ 帙雲系統」 → 「🚀 一鍵初始化系統」**。
4. 等待約 **1 分鐘**。
5. 出現成功提示：*「✅ 系統建構成功！」* 即表示安裝完成。

### 系統自動建立嘅項目

安裝完成後，以下項目會自動建立於您嘅 Google Drive：

```
📁 帙雲/
├── 1. 上傳課業Link（學生）     ← 學生上傳課業至此
├── 2. 待批改課業               ← 系統自動分類課業至此
├── 3. 老師回饋區               ← 老師放置批改後檔案
├── 4. 已發還課業               ← 系統自動發還至學生個人資料夾
├── 帙雲 - 自動共用、收集位址    ← 學生帳號管理試算表
├── 帙雲 - 繳交紀錄及課業佈置   ← 課業設定及繳交紀錄試算表
├── 帙雲 - OverdueAssignments   ← 自動生成逾期名單
└── （安裝檔試算表）
```

安裝檔試算表頁面會自動更新，列出所有項目嘅連結方便存取。

### 自動觸發器設定

| 觸發器 | 頻率 | 功能 |
|--------|------|------|
| `sortStudentAssignments` | 每 1 分鐘 | 將上傳區檔案移至「待批改課業」 |
| `createFoldersAndUpdateSheet` | 每 5 分鐘 | 建立學生資料夾；更新繳交狀況 |
| `autoShareStudentFolders` | 每 5 分鐘 | 將個人資料夾共用至學生帳號 |
| `distributeHomework` | 每 15 分鐘 | 將老師批改後檔案發還至學生 |
| `generateOverdueAssignments` | 每 1 分鐘 | 更新逾期課業報告 |

## 5. 步驟三：啟用控制面板（Web App）

老師控制面板以 Google Apps Script **網頁應用程式（Web App）** 形式提供。

1. 打開安裝檔試算表。
2. 點擊頂部選單 **「擴充功能」 → 「Apps Script」**。
3. 在 Apps Script 編輯器中，點擊右上角藍色按鈕 **「部署」 → 「新增部署作業」**。
4. 點擊左上角「選取類型」旁邊嘅 ⚙️ 齒輪，選擇 **「網頁應用程式」**。
5. 填寫以下設定：

   | 欄位 | 設定值 |
   |------|--------|
   | 說明 | `版本1`（或任意描述） |
   | 執行身分 | **我**（您嘅學校電郵） |
   | 誰可以存取 | **任何人（包含匿名使用者）** 或 **網域內的所有人** |

6. 點擊 **「部署」**。
7. 複製畫面上顯示嘅 **網頁應用程式網址（Web App URL）**，此為您嘅**老師控制面板**，請加入書籤。

> **安全建議：** 如只想學校人員可存取，請選擇「網域內的所有人」。

## 6. 步驟四：部署學生繳交介面

學生繳交介面係同一 Apps Script 專案嘅**另一個部署版本**，讓學生可以選擇課業、輸入姓名並上傳檔案，而無法進入老師控制面板。

1. 返回 Apps Script 編輯器。
2. 依照步驟三嘅方法，**新增另一個部署作業**。
3. 「誰可以存取」設定為 **「任何人（包含匿名使用者）」**，方便無學校帳號嘅學生使用。
4. 將所得嘅 URL 分享給學生，作為**課業繳交連結**。

> 老師控制面板網址和學生繳交網址係**不同 URL**，指向同一 Web App 嘅不同頁面。

## 7. 步驟五：設定學生帳號（自動共用）

要讓每位學生收到其個人「已發還課業」資料夾，需在**「帙雲 - 自動共用、收集位址」**試算表中登記學生資料。

### 如何新增學生

1. 從安裝檔試算表或 Google Drive 開啟**「帙雲 - 自動共用、收集位址」**。
2. 試算表有三欄：

   | A 欄 | B 欄 | C 欄 |
   |------|------|------|
   | 學號 | 姓名 | 專屬文件夾位址（系統自動填寫） |

3. 在 A 欄輸入學生學號（例如 `s12345`），B 欄輸入全名（必須與繳交紀錄試算表中嘅名字**完全一致**）。
4. C 欄會在約 5 分鐘內由 `autoShareStudentFolders` 自動填入資料夾連結。

若 C 欄顯示 `「共用失敗: ...」`，請檢查：
- 學號及電郵域名是否正確。
- 學生 Google 帳號是否存在。
- Apps Script 專案是否已啟用 **Drive API v3** 進階服務。

### 啟用 Drive API v3（如未啟用）

1. 在 Apps Script 編輯器中，點擊左側邊欄**「服務」**（`+` 圖示）。
2. 搜尋 **"Drive API"** → 選擇版本 **v3** → 點擊**「新增」**。

## 8. 步驟六：輸入班別及學生名單

課業記錄及資料夾結構由**「帙雲 - 繳交紀錄及課業佈置」**試算表控制。

### 試算表格式（每個頁籤代表一個班別）

| 儲存格 | 內容 |
|--------|------|
| A1 | 班別名稱（例如 `1A`），亦為頁籤名稱 |
| B1、C1、D1… | 課業名稱（格式：`「科目」「類別」作業名稱【關鍵詞】`，由系統自動格式化） |
| B2、C2、D2… | 截止日期（格式：`YYYY-MM-DD HH:MM`） |
| B3、C3、D3… | 資料夾 ID（系統自動填入，請勿修改） |
| A4、A5、A6… | 學生姓名（必須與自動共用表中嘅姓名完全一致） |
| B4 起 | 繳交狀況（系統自動更新：`已繳交` / `遲交` / `未繳交`） |

### 如何新增班別

1. 在繳交紀錄試算表底部點擊 **+** 新增頁籤。
2. 將頁籤命名為班別名稱（例如 `2B`）。
3. 在 **A1** 儲存格輸入相同嘅班別名稱（`2B`）。
4. 在 **A4** 及以下儲存格逐行輸入學生姓名。
5. 系統會在約 5 分鐘內自動建立對應嘅資料夾結構。

## 9. 系統資料夾及檔案結構

```
📁 帙雲/
│
├── 1. 上傳課業Link（學生）/
│   └── （學生上傳嘅檔案，命名格式：班別_姓名_關鍵詞.副檔名）
│
├── 2. 待批改課業/
│   └── 1A/
│       ├── 閱讀/
│       │   └── 【關鍵詞】/
│       ├── 寫作（長文）/
│       │   └── 【關鍵詞】/
│       └── 寫作（實用文）/
│           └── 【關鍵詞】/
│
├── 3. 老師回饋區/
│   └── （老師放置批改後檔案，命名需包含班別及學生姓名）
│
└── 4. 已發還課業/
    └── 【1A】/
        └── 【學生姓名】/
            ├── 閱讀/
            ├── 寫作（長文）/
            │   └── 課業標題/
            └── 寫作（實用文）/
```
