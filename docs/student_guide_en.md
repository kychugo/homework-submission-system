## 1. How to Submit Homework

Your teacher will give you a **Student Submission URL**. Open it in any web browser, follow the on-screen steps, and upload your homework files.

> **Tip:** Save the URL as a bookmark for easy access next time!

---

## 2. Step-by-Step Walkthrough

### Step 1: Select Your Class
- Open the student submission URL
- Choose your class from the **Class** dropdown (e.g., 1A, 2B)
- Click **Next ➜**

### Step 2: Select Your Name
- Choose your name from the **Student Name** dropdown
- If your name is not listed, let your teacher know so they can update the class list
- Click **Next ➜**

### Step 3: Select the Assignment
- Choose the assignment you are submitting from the **Assignment** dropdown
- If the assignment is not listed, ask your teacher whether it has been posted
- Click **Next ➜**

### Step 4: Upload Your Files
- The top of the page shows your class, name, and assignment — confirm they are correct
- **Upload method 1:** Click the upload box and select files in the popup window
- **Upload method 2:** Drag and drop files directly into the upload box
- You can select **multiple files** at once (e.g., several photos of a handwritten assignment)
- Review the file list, then click **📤 Submit Homework**

### After Submission
- A success page showing "✅ Submission successful!" and the uploaded filenames will appear
- If an error occurs, refer to the FAQ section below

## 3. File Upload Guidelines

| Item | Details |
|------|---------|
| **Supported formats** | Any format: PDF, Word, images (JPG/PNG), video, etc. |
| **Maximum file size** | **48 MB** per file |
| **Number of files** | No limit — upload as many as needed |
| **Recommendation** | For handwritten work, take clear, well-lit photos before uploading |

**How your files are renamed:**  
The system automatically renames uploaded files to: `Class_Name_Keyword_Number.extension`  
For example: `1A_ChanTaiman_Treasure_1.jpg`

---

## 4. Checking Submission Status

The student app does not currently have a built-in status checker. To confirm your submission:
- Look for the "✅ Submission successful!" message after uploading
- If in doubt, ask your teacher to check the submission record

## 5. FAQ

**Q: The page shows "System not configured yet"**  
A: Notify your teacher — the system may not be fully set up yet.

**Q: The dropdown is empty / my name isn't in the list**  
A: Notify your teacher to update the class list.

**Q: I didn't see a success message after uploading**  
A: Do not press submit again immediately. Wait up to 2 minutes (large files take longer). If nothing happens, refresh the page and try again.

**Q: Can I submit homework from my phone?**  
A: Yes — the submission page is mobile-friendly.

**Q: I submitted the wrong assignment — what should I do?**  
A: Tell your teacher. They can delete the incorrect file from the "Pending Homework" folder in Google Drive. Then resubmit using the correct assignment selection.

**Q: Can I upload files in multiple sessions?**  
A: Yes. Each submission adds new files and does not overwrite previous uploads.

**Q: My file is too large to upload**  
A: The limit is 48 MB per file. For images, try compressing them first. For videos, ask your teacher if a Google Drive link is acceptable instead.
