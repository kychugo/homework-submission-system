## 1. 進入控制面板

老師控制面板係透過 Google Apps Script 部署嘅網頁應用程式。

1. 開啟安裝時儲存嘅**老師控制面板網址**（書籤）。
2. 頁面顯示以下功能按鈕：

   | 按鈕 | 目標 |
   |------|------|
   | 學生上傳區 | 學生上傳課業嘅 Google Drive 資料夾 |
   | 待批改課業 | 已分類、待批改嘅課業檔案 |
   | 老師回饋區 | 放置批改後檔案供發還之用 |
   | 已發還課業 | 學生個人資料夾（已發還課業） |
   | 繳交紀錄查閱 | 課業繳交狀況可視化表格 |
   | 課業設置 | 布置課業介面 |
   | 底層：繳交/佈置表 | 直接連結至底層 Google 試算表 |
   | 手動發還課業 | 立即觸發發還流程的按鈕 |

## 2. 布置課業

### 使用課業設置介面

1. 在控制面板點擊 **「課業設置」**。
2. 填寫以下欄位：

   | 欄位 | 說明 |
   |------|------|
   | 選擇班別 | 選擇目標班別（例如 `1A`、`2B`） |
   | 選擇科目 | 選擇科目（例如 `中文`、`英文`），可在**「課業類別設定」**中增刪 |
   | 選擇課業類別 | 選擇類別（例如 `閱讀`、`寫作（長文）`），可在**「課業類別設定」**中增刪 |
   | 課業名稱 | 輸入完整課業題目（例如：`藏在泥土的寶物`） |
   | 關鍵詞 | 輸入課業名稱中的關鍵詞（例如：`寶物`），學生需在檔案名稱中包含此關鍵詞 |
   | 截止日期和時間 | 使用**日期選擇器**選擇，或直接在下方文字框輸入（格式：`YYYY-MM-DD HH:MM`，例如：`2025-04-24 23:59`） |

3. 點擊 **「提交」**，確認視窗會顯示所有已填資料。
4. 點擊 **「確定」** 確認，或 **「取消」** 返回修改。

確認後，課業資料會寫入**「帙雲 - 繳交紀錄及課業佈置」**試算表，系統在約 5 分鐘內自動建立對應資料夾。

### 截止日期格式

系統接受 `YYYY-MM-DD HH:MM`（24 小時制）格式，同時支援日期選擇器：

```
2025-04-24 23:59   ← 2025 年 4 月 24 日晚上 11:59
2025-06-01 08:00   ← 2025 年 6 月 1 日上午 8:00
```

直接輸入數字，表格會自動格式化。

### 課業名稱格式化方式

提交後，系統會將課業名稱格式化為：

```
「科目」「類別」課業名稱【關鍵詞】
```

**例子：**
- 科目：`中文`
- 類別：`寫作（長文）`
- 名稱：`藏在泥土的寶物`
- 關鍵詞：`寶物`
- 結果：`「中文」「寫作（長文）」藏在泥土的寶物【寶物】`

此格式化名稱用於建立對應嘅 Drive 資料夾，以及匹配學生上傳嘅檔案。

### 直接編輯試算表布置課業

亦可直接編輯**「帙雲 - 繳交紀錄及課業佈置」**試算表布置課業：

1. 從控制面板開啟（「底層：繳交/佈置表」）。
2. 切換至目標班別嘅頁籤（例如 `1A`）。
3. 在下一個空白欄位（從 B 欄開始）：
   - **第 1 行**：輸入格式化後的課業名稱（例如 `「中文」「閱讀」作業名稱【關鍵詞】`）
   - **第 2 行**：輸入截止日期（例如 `2025-04-24 23:59`）
4. **請勿**修改第 3 行（資料夾 ID，由系統自動管理）。

## 3. 查看繳交狀況

### 繳交紀錄儀表板

1. 在控制面板點擊 **「繳交紀錄查閱」**。
2. 點擊班別按鈕查看該班表格。
3. 表格顯示每位學生每份課業的繳交狀況：

   | 顏色 | 狀況 |
   |------|------|
   | 🟢 綠色 | 已準時繳交（已繳交） |
   | 🟡 黃色 | 遲交（遲交） |
   | 🔴 紅色 | 未繳交（未繳交） |

系統每 **5 分鐘**自動更新一次。

### 底層試算表

如需更詳細嘅資料，直接開啟**「帙雲 - 繳交紀錄及課業佈置」**試算表，顏色編碼與儀表板相同，可以篩選或匯出。

## 4. 查閱待批改課業

所有學生上傳嘅檔案會自動分類至**「2. 待批改課業」**資料夾結構：

```
2. 待批改課業/
└── 1A/
    ├── 閱讀/
    │   └── 課業關鍵詞/
    │       └── 1A陳大文寶物.pdf
    ├── 寫作（長文）/
    │   └── 課業關鍵詞/
    └── 寫作（實用文）/
```

1. 從控制面板開啟 **「待批改課業」**。
2. 進入對應班別及科目資料夾。
3. 開啟並批改各學生嘅檔案。

## 5. 批改及發還課業

批改完一個學生嘅檔案後，將批改後嘅版本放入 **「3. 老師回饋區」** 資料夾，系統會在 15 分鐘內自動將其移至該學生在**「4. 已發還課業」**嘅個人資料夾。

### 發還檔案命名規則

為確保系統能正確路由檔案，檔案名稱應包含：
- **班別名稱**（例如 `1A`）
- **學生全名**（例如 `陳大文`）
- 可選：**課業關鍵詞**（例如 `寶物`）—— 若包含，檔案會被放置至特定課業子資料夾

**例子：**

| 檔案名稱 | 發還至 |
|---------|-------|
| `1A陳大文寶物批改.pdf` | `【1A】/【陳大文】/寫作（長文）/課業標題/` |
| `1A陳大文.pdf` | `【1A】/【陳大文】/`（學生根目錄） |
| `1A.pdf` | `【1A】/`（班別根目錄） |

## 6. 手動觸發發還

發還流程每 15 分鐘自動執行一次。如需立即執行：

**經控制面板：**
1. 點擊控制面板上嘅 **「手動發還課業」** 按鈕。
2. 按鈕會顯示「正在發還中...」，處理完成後出現成功或錯誤提示。

**經試算表選單：**
1. 打開安裝檔試算表。
2. 點擊 **「☁️ 帙雲系統」 → 「📤 手動立即發還課業」**。

## 7. 管理班別及學生

### 新增班別

1. 開啟**「帙雲 - 繳交紀錄及課業佈置」**。
2. 點擊底部 **+** 新增頁籤，以班別名稱命名（例如 `2B`）。
3. 在 **A1** 儲存格輸入班別名稱（`2B`）。
4. 從 **A4** 起逐行輸入學生姓名。

### 於現有班別新增學生

1. 開啟對應班別嘅頁籤。
2. 在 A 欄最後一名學生之後的空行新增學生姓名（從第 4 行起）。
3. 同時在**「帙雲 - 自動共用、收集位址」**中新增該學生（A 欄 = 學號，B 欄 = 全名），以便自動共用其個人資料夾。

### 移除學生

建議保留學生名字以作記錄。從 A 欄刪除名字後，系統將停止為其更新繳交記錄。

## 8. 查看逾期名單

系統在**「帙雲 - OverdueAssignments」**自動維護逾期名單。

1. 從 Google Drive 的 `📁 帙雲` 資料夾開啟該檔案。
2. 「Overdue Assignments」工作表包含以下欄位：

   | 欄位 | 內容 |
   |------|------|
   | 班別 | 班別 |
   | 學生姓名 | 學生姓名 |
   | 學生電郵 | 學生電郵 |
   | 課業名稱 | 課業名稱 |
   | 截止日期 | 截止日期 |

此名單只顯示截止日期已過但**仍未繳交**嘅學生，可作跟進或提醒之用。

## 9. 課業類別及科目設定

### 透過設定面板管理

控制面板有一個專屬嘅 **「課業類別設定」** 頁面，讓你直接在瀏覽器中新增或刪除類別和科目，無需修改任何程式碼。

1. 在控制面板點擊 **「課業類別設定」**。
2. 頁面分為兩個部分：

   **課業類別（Category）**
   - 顯示現有類別（例如 `閱讀`、`寫作（長文）`）。
   - 點擊「新增」可加入自訂類別（例如 `默書`、`朗讀`）。
   - 點擊「刪除」可移除不需要的類別。

   **科目（Subject）**
   - 顯示現有科目（例如 `中文`、`英文`、`數學`、`常識`）。
   - 點擊「新增」可加入自訂科目（例如 `普通話`、`體育`）。
   - 點擊「刪除」可移除不需要的科目。

> ⚠️ 刪除類別或科目後，已建立的資料夾不受影響，但新布置的課業將不再提供該選項。

### 預設值

| 科目 | 類別 |
|------|------|
| 中文 | 閱讀 |
| 英文 | 寫作（長文） |
| 數學 | 寫作（實用文） |
| 常識 | |

以上為系統預設，可隨時透過設定面板修改。
