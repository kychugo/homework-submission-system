## 1. 系統概覽

帙雲系統由兩個獨立的 Google Apps Script 網頁應用程式組成：

| 系統 | 用途 | 使用者 |
|------|------|--------|
| **主系統** | 布置課業、查閱繳交紀錄、管理學生資料夾、自動共用 | 老師 |
| **學生提交系統** | 交作業（選擇班別、姓名、課業，上傳檔案） | 學生 |

兩個系統使用同一個 Google Drive 作儲存後端，但部署為獨立網頁，學生只能存取學生系統，無法看到老師的布置課業功能。

---

## 2. 部署前準備

**所需 Google 帳號條件：**
- 需要一個 Google 帳號（建議使用老師的學校帳號）
- 帳號需已啟用 Google Drive 及 Google Sheets

**所需工具：**
- 瀏覽器（建議 Chrome）
- 此 GitHub 儲存庫的所有原始碼檔案

## 3. 主系統部署（老師用）

### 步驟 1：建立 Google Apps Script 專案

1. 前往 [script.google.com](https://script.google.com)
2. 點擊「**新增專案**」
3. 專案名稱建議改為：`帙雲主系統`

### 步驟 2：複製代碼

將以下檔案的內容逐一複製到 Apps Script 編輯器：

| 原始碼檔案 | 在 Apps Script 中的名稱 |
|-----------|------------------------|
| `code.gs` | `code.gs`（預設已有） |
| `Index.html` | 新增 HTML 檔案 → 命名為 `Index` |
| `homework.html` | 新增 HTML 檔案 → 命名為 `homework` |
| `record.gs`（HTML 內容） | 新增 HTML 檔案 → 命名為 `record` |
| `config.html` | 新增 HTML 檔案 → 命名為 `config` |
| `autoshare.html` | 新增 HTML 檔案 → 命名為 `autoshare` |
| `setup.gs` | 新增 `.gs` 檔案 → 命名為 `setup` |

> **提示**：在 Apps Script 左側點擊「+」即可新增檔案，選擇「HTML 檔案」或「指令碼檔案」。

### 步驟 3：啟用 Drive API（進階服務）

1. 在 Apps Script 左側，點擊「**服務**」旁的「**+**」
2. 找到「**Drive API**」，點選並啟用（版本選 `v3`）
3. 按「**儲存**」

### 步驟 4：部署為網頁應用程式

1. 點擊右上角「**部署**」→「**新增部署**」
2. 部署類型選「**網頁應用程式**」
3. 設定如下：
   - **執行者**：以我自己（老師帳號）的身分執行
   - **存取權限**：任何 Google 帳號均可存取 *(或根據學校政策選擇)*
4. 點擊「**部署**」，複製生成的**網頁應用程式 URL**（這就是老師控制面板網址）

### 步驟 5：綁定試算表（建立選單）

1. 在 Google Sheets 建立一個新試算表（或使用現有的）
2. 點擊「**擴充功能**」→「**Apps Script**」
3. 在此 Apps Script 中，只需複製 `setup.gs` 內容即可
4. 儲存並重新整理試算表，頂部選單會出現「☁️ 帙雲系統」

## 4. 學生提交系統部署（學生用）

學生提交系統需要**另一個獨立的 Apps Script 專案**。

### 步驟 1：建立新的 Apps Script 專案

1. 前往 [script.google.com](https://script.google.com) → 新增專案
2. 命名為：`帙雲學生提交`

### 步驟 2：複製學生系統代碼

| 原始碼檔案 | 在 Apps Script 中的名稱 |
|-----------|------------------------|
| `student.gs` | `code.gs`（覆蓋預設的空白檔案） |
| `student_submit.html` | 新增 HTML 檔案 → 命名為 `student_submit` |

### 步驟 3：設定指令碼屬性

1. 在 Apps Script 點擊左側「**⚙ 專案設定**」
2. 向下捲動到「**指令碼屬性**」→ 點擊「**新增屬性**」
3. 填入以下兩個屬性：

   | 屬性名稱 | 值 |
   |---------|---|
   | `UPLOAD_FOLDER_ID` | 帙雲「1. 上傳課業Link（學生）」資料夾的 ID |
   | `RECORD_SHEET_ID` | 帙雲「繳交紀錄及課業佈置」試算表的 ID |

> **如何找到資料夾/試算表 ID？**
> 開啟 Google Drive 中的資料夾或試算表，網址列中 `/folders/` 或 `/d/` 後的一串字母數字就是 ID。
> 例如：`https://drive.google.com/drive/folders/1aBcD...XyZ` → ID 是 `1aBcD...XyZ`

### 步驟 4：部署為網頁應用程式

1. 點擊「部署」→「新增部署」→ 類型選「網頁應用程式」
2. 設定：
   - **執行者**：以我自己的身分執行
   - **存取權限**：**任何人（包括匿名）** ← 重要！讓未登入的學生也能使用
3. 部署後複製**學生提交網址**，此網址可安全地分享給學生

## 5. 初始化系統

主系統**第一次使用**前，需執行初始化：

1. 開啟綁定了 `setup.gs` 的 Google 試算表
2. 點擊頂部選單「**☁️ 帙雲系統**」→「**🚀 一鍵初始化系統**」
3. 等待約 1 分鐘，系統會自動在 Google Drive 建立以下資料夾和試算表：
   - 📁 帙雲（主資料夾）
     - 1. 上傳課業Link（學生）
     - 2. 待批改課業
     - 3. 老師回饋區
     - 4. 已發還課業
   - 帙雲 - 自動共用、收集位址（試算表）
   - 帙雲 - 繳交紀錄及課業佈置（試算表）
   - 帙雲 - OverdueAssignments（試算表）
4. 初始化完成後，試算表會顯示所有連結

## 6. 新增學生帳號（自動共用設定）

為每位學生設定已發還課業資料夾的共用權限。

### 方法一：透過「自動共用管理」面板（推薦）

1. 前往老師控制面板 → 點擊「**自動共用管理**」
2. 填入學生的「學號」和「姓名」→ 點擊「新增學生」
3. 所有學生新增完成後，點擊「**立即執行自動共用**」

### 方法二：直接編輯試算表

開啟「帙雲 - 自動共用、收集位址」試算表，在 A 欄填入學號，B 欄填入姓名（與繳交紀錄試算表中的姓名完全一致）。

> **注意：** 學號必須是學生 Google 帳號的前綴（例如學號 `21001` 對應帳號 `21001@ccckyc.edu.hk`）。如需更改域名，請修改 `code.gs` 中的 `@ccckyc.edu.hk` 部分。

## 7. 設定科目與類別

1. 前往老師控制面板 → 點擊「**科目／類別設定**」
2. 點擊「**➕ 新增科目**」，輸入科目名稱（如：英文、數學）
3. 在每個科目的卡片內，點擊「**➕ 新增類別**」，輸入課業類別
4. 完成後點擊「**💾 儲存設定**」

系統預設已有「中文」科目及三個類別。

---

## 8. 更新及重置

- **更新代碼**：在 Apps Script 中貼上新代碼後，重新部署即可（選「管理部署」→「編輯」→ 版本改為「新版本」）
- **重置安裝**：點擊選單中的「⚠️ 重置安裝狀態」，然後重新執行初始化（**警告**：這只重置系統屬性，不會刪除 Drive 中的資料）

## 9. 常見問題

**Q: 初始化失敗，提示「沒有權限」**
A: 確認 Drive API（v3）已在「服務」中啟用。

**Q: 自動共用顯示「共用失敗」**
A: 確認學號對應的 Google 帳號確實存在，以及 Drive API 已啟用。

**Q: 學生無法開啟提交頁面**
A: 確認學生提交系統的存取權限設為「任何人（包括匿名）」。

**Q: 修改代碼後學生用的是舊版**
A: 部署時必須選「新版本」而非「使用現有版本」。

**Q: 如何新增班別？**
A: 在「帙雲 - 繳交紀錄及課業佈置」試算表中新增一個分頁，A1 填入班別名稱，A4 起填入學生名單即可。
