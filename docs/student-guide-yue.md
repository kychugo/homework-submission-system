| 項目 | 說明 |
|------|------|

## 2. 如何繳交課業

繳交課業有兩種方法，老師會通知你使用哪種方法。

### 方法一 — 學生繳交介面（推薦）

1. 在瀏覽器中開啟老師提供嘅**學生繳交連結**。
2. 繳交介面載入後，填寫以下資料：
   - **選擇課業** — 從下拉選單選擇你正在提交嘅功課。
   - **你嘅姓名** — 輸入你嘅全名（必須與班級名單一致，例如：`陳大文`）。
   - **上傳檔案** — 點擊上傳按鈕，選擇一個或多個檔案。
3. 點擊**「提交」**。
4. 等待確認提示出現後才可關閉頁面。

> 可以**一次上傳多個檔案**。  
> 接受任何檔案格式。

---

### 方法二 — 直接上傳至 Google Drive

若老師給了你一個 **Google Drive 資料夾連結**：

1. 在瀏覽器開啟連結（如有提示，請以學校 Google 帳號登入）。
2. 點擊左上角 **「+ 新增」 → 「上傳檔案」**。
3. 選擇你的檔案（可以同時選擇多個檔案）。
4. 等待上傳完成（畫面底部會出現進度條）。

#### ⚠️ 重要：檔案命名格式

直接上傳至 Google Drive 時，檔案名稱**必須**符合以下格式，系統才能正確分類：

```
[班別][姓名][關鍵詞].[副檔名]
```

**例子：**

| 課業 | 正確檔案名稱 |
|------|------------|
| 1A 班，學生陳大文，關鍵詞「寶物」 | `1A陳大文寶物.pdf` |
| 2B 班，學生李小明，關鍵詞「環保」 | `2B李小明環保.jpg` |

- 檔案名稱必須包含**班別**（例如 `1A`、`2B`）。
- 必須包含你嘅**全名**（與班級名單完全一致）。
- 必須包含該課業嘅**關鍵詞**（老師會告知）。

若檔案名稱未包含班別、姓名及關鍵詞，系統可能無法正確分類你嘅檔案。

## 3. 檔案命名規則

| 規則 | 說明 |
|------|------|
| 包含班別 | 例如 `1A`、`2B`、`3C` |
| 包含全名 | 必須與班級名單完全一致 |
| 包含課業關鍵詞 | 由老師為每份課業提供 |
| 檔案格式 | 任何格式均可 |
| 多個檔案 | 允許，每個檔案均需遵守命名格式 |

## 4. 一次提交多個檔案

- **經學生介面：** 上傳按鈕支援同時選擇多個檔案。Windows 用戶可按住 `Ctrl` 鍵多選，Mac 用戶可按住 `Cmd` 鍵多選。
- **直接上傳至 Drive：** 在檔案選擇器中一次選擇所有檔案，或逐一上傳至同一資料夾。

每個檔案均應遵守命名格式，以確保系統能正確識別你嘅提交。

## 5. 查看繳交狀況

老師或許會分享一個**作業繳交紀錄頁面**，讓你查看課業是否已成功收妥。

1. 開啟老師提供嘅繳交紀錄連結。
2. 點擊你所屬嘅**班別按鈕**（例如 `1A`）查看繳交表格。
3. 在左欄找到你嘅姓名。
4. 每份課業對應嘅儲存格顏色含義如下：

   | 顏色 | 含義 |
   |------|------|
   | 🟢 綠色 | 已準時繳交 |
   | 🟡 黃色 | 遲交 |
   | 🔴 紅色 | 未繳交 |

> 系統大約每 **5 分鐘**更新一次繳交狀況。

## 6. 取回已批改課業

老師批改並發還課業後，檔案會出現在你嘅**個人 Google Drive 資料夾**中。

1. 老師（或系統）會將一個 Google Drive 資料夾共用至你嘅學校帳號。
2. 進入 **Google Drive** → **「與我共用」**，尋找名為 `【你嘅姓名】` 嘅資料夾。
3. 資料夾內嘅批改課業會按科目及課業標題分類存放。

若找不到資料夾，請聯絡老師，確認你嘅學號及姓名是否已登記於系統。

## 7. 常見問題及解決方法

| 問題 | 可能原因 | 解決方法 |
|------|---------|--------|
| 繳交紀錄未顯示我的檔案 | 檔案命名格式不符 | 按照命名規則重新命名後再上傳 |
| 已上傳但仍顯示「未繳交」 | 系統每 5 分鐘更新一次 | 等候 5–10 分鐘後重新整理頁面 |
| 無法開啟繳交連結 | 可能需要登入學校帳號 | 確保已用學校 Google 帳號登入後再開啟連結 |
| 已發還課業資料夾未共用 | 學號未登記於系統 | 聯絡老師，請其在「自動共用、收集位址」表新增你的學號 |
| 不小心上傳了錯誤檔案 | 錯誤檔案已上傳 | 聯絡老師，請其從「待批改課業」資料夾刪除錯誤檔案 |
| 繳交介面無法載入 | 網絡問題或 Web App 錯誤 | 嘗試重新整理頁面；若問題持續，請聯絡老師 |
