## 2. How to Submit Homework

There are two ways to submit homework. Your teacher will tell you which method to use.

### Option A — Student Submission Panel (Recommended)

1. Open the **Student Submission Link** provided by your teacher in your browser.
2. The submission panel will load. Fill in the following:
   - **Select homework** — Choose the assignment you are submitting from the dropdown.
   - **Your name** — Enter your full name exactly as registered (e.g., `陳大文`).
   - **Upload file(s)** — Click the upload button and select one or more files.
3. Click **Submit**.
4. Wait for the confirmation message before closing the page.

> You may attach **more than one file** in a single submission.  
> All file formats are accepted.

---

### Option B — Direct Drive Upload

If your teacher gave you a **Google Drive folder link** for uploading:

1. Open the link in your browser (sign in with your school Google account if prompted).
2. Click the **+ New** button (top-left) → **File upload**.
3. Select your file(s). You can select multiple files at once.
4. Wait for the upload to complete (a progress bar appears at the bottom of the screen).

#### ⚠️ Critical: File naming format

When uploading directly to Google Drive, your file name **must** follow this format so the system can sort it correctly:

```
[Class][StudentName][Keyword].[extension]
```

**Examples:**

| Assignment | Correct file name |
|-----------|-------------------|
| Class 1A, student 陳大文, homework keyword 寶物 | `1A陳大文寶物.pdf` |
| Class 2B, student 李小明, homework keyword 環保 | `2B李小明環保.jpg` |

- The **class name** (e.g. `1A`, `2B`) must appear in the filename.
- Your **full name** must appear exactly as it is in the class list.
- The **keyword** for the homework must appear (your teacher will tell you the keyword).

If the filename does not include your class, name, and keyword, the system may not be able to sort your file.

## 3. File Naming Rules

| Rule | Details |
|------|---------|
| Include class name | E.g. `1A`, `2B`, `3C` |
| Include your full name | Exactly as it appears in the class register |
| Include homework keyword | Provided by your teacher for each assignment |
| File format | Any format is accepted |
| Multiple files | Allowed — each file should follow the same naming format |

## 4. Submitting Multiple Files

- **Via the Student Panel:** The upload button allows you to select multiple files at once. Hold `Ctrl` (Windows) or `Cmd` (Mac) while clicking to select more than one file.
- **Via Direct Drive Upload:** Select all files together in the file picker, or upload them one by one to the same folder.

Each file should still follow the file naming format so the system can identify your submission correctly.

## 5. Checking Your Submission Status

Your teacher may share a **submission record page** (作業繳交紀錄) where you can see whether your homework has been received.

1. Open the submission record link provided by your teacher.
2. Click your **class button** (e.g. `1A`) to show the submission table.
3. Find your name in the left column.
4. The cell for each homework will be coloured:

   | Colour | Meaning |
   |--------|---------|
   | 🟢 Green | Submitted on time |
   | 🟡 Yellow | Submitted late |
   | 🔴 Red | Not yet submitted |

> The table is updated approximately every **5 minutes** by the system.

---

## 6. Accessing Your Returned Homework

Once your teacher has marked and returned your homework, it will appear in your **personal Google Drive folder**.

1. Your teacher (or the system) will have shared a Google Drive folder with your school account.
2. Go to **Google Drive** → **Shared with me** to find the folder named `【YourName】`.
3. Inside, you will find your returned homework organised by subject and assignment title.

If you cannot see the folder, contact your teacher to check that your student number and name have been registered in the system.

## 7. Common Problems & Solutions

| Problem | Possible Cause | Solution |
|---------|---------------|----------|
| My file is not showing in the submission record | File name does not match the required format | Rename your file to include class, name, and keyword; re-upload |
| I uploaded the file but it shows "未繳交" (not submitted) | The system updates every 5 minutes | Wait 5–10 minutes and refresh the page |
| I cannot open the submission link | You may need to sign in with your school account | Open the link in a browser where you are signed in with your school Google account |
| My returned homework folder is not shared with me | Your student ID may not be registered | Ask your teacher to add your student ID to the "自動共用、收集位址" sheet |
| I submitted the wrong file | The file has already been uploaded | Contact your teacher — they can delete the incorrect file from the "待批改課業" folder |
| The submission panel does not load | Network issue or Web App error | Try refreshing the page; if problem persists, contact your teacher |
