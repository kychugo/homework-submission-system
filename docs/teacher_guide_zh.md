## 1. 控制面板概覽

開啟**老師控制面板網址**後，你會看到三個區域：

| 區域 | 按鈕 | 功能 |
|------|------|------|
| **資料夾連結** | 學生上傳區、待批改課業、老師回饋區、已發還課業 | 直接開啟對應 Google Drive 資料夾 |
| **系統功能** | 繳交紀錄查閱、布置課業、底層試算表、手動發還課業 | 主要教學功能 |
| **設定管理** | 科目／類別設定、自動共用管理、共用位址表 | 系統設定 |

## 2. 設定科目與類別

**初次使用前**，建議先設定你的科目和各科的課業類別。

1. 前往控制面板 → 點擊「**科目／類別設定**」
2. 如需新增科目（如英文、數學）：
   - 在頂部輸入框填入科目名稱 → 點擊「**➕ 新增科目**」
3. 為每個科目新增課業類別（如：閱讀、寫作、作文）：
   - 在對應科目的卡片中輸入類別名稱 → 點擊「**➕ 新增類別**」
4. 如需刪除科目或類別，點擊對應的「**🗑️ 刪除**」
5. 完成後點擊「**💾 儲存設定**」

> **注意：** 每個科目的類別完全獨立設定，不會互相影響。

## 3. 布置課業

1. 前往控制面板 → 點擊「**布置課業**」
2. 填寫以下資料：

   | 欄位 | 說明 |
   |------|------|
   | **班別** | 選擇要布置課業的班別 |
   | **科目** | 選擇科目（根據設定中的科目） |
   | **課業類別** | 選擇此科目下的類別（根據設定中的類別） |
   | **課業名稱** | 課業的完整名稱（例如：藏在泥土的寶物） |
   | **關鍵詞** | 必須是課業名稱的一部分，用於自動排序檔案（例如：寶物） |
   | **截止日期和時間** | 可用日期選擇器點選，或手動輸入（格式：年-月-日 時:分） |

3. 填寫完畢後點擊「**提交**」
4. 確認視窗顯示後，核對資料正確，點擊「**確定**」

**課業名稱格式說明：**  
提交後，系統會自動將課業名稱格式化為：  
`「科目」「類別」課業名稱【關鍵詞】`  
例如：`「中文」「閱讀」藏在泥土的【寶物】`

此格式用於 Google Drive 資料夾的自動分類，請不要手動修改試算表中的課業名稱格式。

## 4. 查閱繳交紀錄

1. 前往控制面板 → 點擊「**繳交紀錄查閱**」
2. 頁面頂部有各班別的按鈕，點擊即可查看該班的繳交狀況
3. 表格顏色說明：

   | 顏色 | 狀態 |
   |------|------|
   | 🟩 綠色 | 已按時繳交 |
   | 🟨 黃色 | 遲交 |
   | 🟥 紅色 | 未繳交 |

4. 如需查看更詳細的資料（例如繳交時間），可開啟底層試算表：控制面板 → 「**底層：繳交/佈置表**」

## 5. 批改及發還課業

### 批改課業
1. 前往控制面板 → 點擊「**待批改課業**」
2. 在資料夾中找到對應班別、類別和課業的子資料夾
3. 開啟學生的作業檔案，在同一資料夾或另一個文件中撰寫批改意見
4. 將批改好的檔案移動到「**老師回饋區**」（資料夾路徑：`3. 老師回饋區`）

### 自動發還課業
系統每 15 分鐘會自動將「老師回饋區」的檔案，根據檔案名稱中的班別和學生名字，移動到「已發還課業」中對應學生的資料夾。

如需立即發還，前往控制面板 → 點擊「**手動發還課業**」按鈕。

### 學生收到課業
學生登入後可在自己的「已發還課業」資料夾（已透過自動共用功能設定好權限）查看老師的批改。

## 6. 管理學生帳號（自動共用）

### 新增學生
1. 前往控制面板 → 點擊「**自動共用管理**」
2. 填入學號和姓名 → 點擊「**➕ 新增學生**」
3. 重複以上步驟添加全部學生
4. 完成後點擊「**▶ 立即執行自動共用**」

### 更新學生姓名
輸入相同的學號及新姓名，點擊「新增學生」，系統會自動更新該學號的姓名。

### 刪除學生
在學生列表中，點擊對應學生旁的「🗑️ 刪除」按鈕。  
（注意：刪除後不會自動撤銷已共用的資料夾權限。）

## 7. Google Drive 資料夾結構

```
📁 帙雲
├── 1. 上傳課業Link（學生）     ← 學生交作業暫存區
├── 2. 待批改課業               ← 系統自動分類後的作業
│   └── [班別]
│       └── [類別]
│           └── [課業名稱]      ← 學生作業在此
├── 3. 老師回饋區               ← 老師批改完後放在此
└── 4. 已發還課業               ← 系統自動分發後的位置
    └── 【班別】
        └── 【學生姓名】        ← 此資料夾已與學生共用
            └── [類別]
                └── [課業名稱]
```

## 8. 常見問題

**Q: 布置了課業，但繳交紀錄沒有更新**  
A: 系統每 5 分鐘自動更新一次。請等待幾分鐘後重新整理頁面。

**Q: 學生說他們的資料夾沒有被共用**  
A: 前往「自動共用管理」，確認學生已新增，然後點擊「立即執行自動共用」。

**Q: 我想手動修改課業的截止日期**  
A: 開啟「底層：繳交/佈置表」試算表，找到對應班別的分頁，直接在第 2 行修改截止日期（格式建議：`2025-04-24 23:59`）。

**Q: 如何新增班別？**  
A: 在「帙雲 - 繳交紀錄及課業佈置」試算表新增一個分頁，A1 填入班別名稱（例如：2A），A4 起填入學生名單。

**Q: 逾期名單在哪裡看？**  
A: 在「帙雲 - OverdueAssignments」試算表，系統每分鐘自動更新一次。
